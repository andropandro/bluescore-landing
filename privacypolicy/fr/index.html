Politique de confidentialité

Vos recherches
restent sur votre appareil.

BlueScore repose sur une promesse simple : les recherches que vous effectuez et les données que l’application en dérive restent sur votre appareil.

Dernière mise à jour : mai 2026

1. Aperçu

BlueScore est développé dans le respect de votre vie privée. Nous ne traitons que les données nécessaires au fonctionnement de l’application et stockons toutes les informations localement sur votre appareil.

2. Informations stockées sur votre appareil

  • Les recherches de lieux que vous effectuez
  • Les données météo pour les destinations que vous consultez
  • Les paramètres et préférences de l’application
  • Les données de journal techniques pour le dépannage et le support

3. Informations non collectées

  • Informations personnellement identifiables
  • Informations de compte ou données utilisateur — BlueScore n’a pas de comptes
  • Images, fichiers média ou contenu personnel
  • Données de localisation continues en arrière-plan
  • Messages personnels ou communications

4. Fichiers de journal et dépannage

L’application crée automatiquement des fichiers de journal sur votre appareil pour aider au dépannage et au support. Ces fichiers contiennent :

  • Informations techniques sur les fonctions de l’application
  • Messages d’erreur et données de performance
  • Horodatages des activités
  • Informations sur l’appareil (version iOS, version de l’application)

Un nouveau fichier de journal est créé à chaque démarrage de l’application et un maximum de cinq fichiers de journal précédents sont sauvegardés automatiquement. Les fichiers de journal ne contiennent aucune information personnelle telle que des noms, des lieux visités ou des paramètres personnels. Les informations sensibles comme les clés d’API sont filtrées automatiquement.

5. Partage des fichiers de journal

Vous pouvez choisir volontairement de partager les fichiers de journal avec notre équipe de support via les paramètres de l’application. Cela ne se produit que lorsque vous choisissez activement d’envoyer un e-mail avec les fichiers en pièces jointes. Aucun fichier de journal n’est envoyé automatiquement ou sans votre consentement.

6. Gestion des données

Toutes les informations sont stockées localement sur votre appareil. Aucune donnée n’est envoyée à nos serveurs ou partagée avec des tiers, sauf lorsque vous choisissez volontairement de partager les fichiers de journal pour le support.

7. Services tiers

Nous utilisons les services externes suivants pour récupérer des informations météo et de lieu :

  • MET Norway API (données météo)
  • GeoNames API (informations de lieu)
  • OpenStreetMap / Overpass API (données géographiques)
  • WeatherAPI.com (données météo supplémentaires)
  • Apple Maps & CoreLocation (données de carte et de lieu)
  • Autres services de données publiques

Ces requêtes sont effectuées sans partager vos informations personnelles. Seuls les noms de lieux et les coordonnées sont envoyés pour récupérer des informations météo et géographiques publiques.

8. Analyses et statistiques

L’application ne collecte pas de statistiques d’utilisation, d’analyses ou de télémétrie. Toutes les informations restent sur votre appareil.

9. Cache et données temporaires

Pour améliorer les performances, l’application stocke temporairement des données météo et des informations de lieu localement. Ce cache :

  • Est stocké uniquement sur votre appareil
  • Est effacé automatiquement après un certain temps
  • Peut être effacé manuellement via les paramètres de l’application
  • Ne contient aucune information personnelle

10. Vos droits

  • Vous pouvez supprimer toutes les informations stockées en désinstallant l’application.
  • Vous pouvez effacer le cache et les fichiers de journal via les paramètres de l’application.
  • Vous pouvez choisir de ne pas partager les fichiers de journal pour le support.
  • Vous contrôlez quelles informations sont stockées localement.

11. Contact

Pour toute question concernant la confidentialité ou la gestion des données, veuillez nous contacter à hello@bluescore.cloud.
